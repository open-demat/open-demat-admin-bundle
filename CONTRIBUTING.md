# Contributing

Thank you for helping improve Open Demat Admin Bundle.

## Development setup

1. Install this bundle in an Open Demat core application.
2. Run `composer install` in the core application.
3. Run the relevant admin bundle tests before submitting changes.

## Pull requests

Please keep changes focused, include tests for behavior changes, and use
conventional commit messages when possible.
